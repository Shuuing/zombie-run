## 바꾼 것 (`Source~/import_landing.py <Assets> [루트 배율] [--force]`)

- **색**: 빨강 → 살짝 푸른 흰 회색(밤 먼지). 파티클 색 전부를 (휘도 + 최댓값)/2 × (0.84, 0.87, 0.94) 로 — 휘도만 쓰면 빨강이 검게 된다.
- **큰 안개 빛 `Glow_Dark`** 불투명도 × 0.45 — 밤 화면에서 밝은 안개처럼 뜨지 않게(사용자는 시작 연출이 밝게 뜨는 걸 싫어한다).
- **깊이 검사 끔**(머티리얼 `_Ztest` 8 = Always): 원작은 바로 위에서 내려다보는 카메라라 카메라를 보는 연기 판이 땅에 걸리지 않지만,
  우리 52° 카메라에선 판 아래 절반이 땅에 묻혀 가로로 잘려 보였다. 캐릭터는 시작 연출 중 큐 4062(평소에도 발밑 링이 4001)라 연기(3000)보다 나중에 그려져 가려지지 않는다.
- **머티리얼은 새 GUID 복사본** `*_Land.mat` 6개(`Glow_011_M1` · `Glow_011_M3` · `Bullet_015_M1` 은 다른 이펙트와 공유라 원본은 그대로).
  텍스처는 원본 GUID — 새로 넣은 것은 `Smoke_022.png` · `Smoke_122.png`(나머지 `Smoke_009` · `Glow_011` · `Glow_010_T1` · `Bullet_015` 는 이미 있었다).
- 빈 껍데기 둘(최상위 · `all`, 렌더러 꺼짐) 5초 반복 · 초당 10개 방출 → 반복 끔 · 방출 0. 최상위 배율 **0.16**(구름 지름 ≈ 3.2m, 0.18 이면 3.6m).
- 프리팹 GUID 새로(`a52ac973…`), 이름 `MFX_Landing_Smoke`. 다시 돌리면 프리팹 · 머티리얼 GUID 는 지킨다(덮어쓰기는 `--force`).

## 게임 연결

FX 카탈로그 `intro_landing` → 이 프리팹(`FxAssetsSetup.IntroLandingPrefab`, 이 파일이 없으면 우리 템플릿 `FX_IntroLanding`). `ProtoIntro.Land`(건너뛰기 아님)가
착지 지점 바닥에 낸다 — 흔들림 · 찌그러짐 · 소리 `land` 는 코드. 0.8초 안에 다 사라진다(카탈로그 수명 1.4).
크기는 FX 툴 카탈로그 탭의 '크기 (프리팹 루트)' 로 바꾼다.

확인: 임시 프로젝트에서 실제 파일로 렌더(`Source~/landing_smoke.gif` 30fps · `landing_smoke_frames.png`). **어둠 막이 있는 게임 화면은 미확인.**

폴더를 지울 땐: 카탈로그 `intro_landing` 을 우리 템플릿 `Art/VFX/Common/FX_IntroLanding` 으로 돌리고 `*_Land.mat` 6개 · `Smoke_022/122.png` · 이 프리팹을 지운다.
