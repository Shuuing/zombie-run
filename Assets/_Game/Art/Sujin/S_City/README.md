## 무엇이 바뀌나

- **원본 머티리얼은 그대로다.** BCM 머티리얼마다 `Materials/<이름>_TFF.mat` 복사본을 만들고, Proto_City_Test 렌더러의 머티리얼 칸만 바꾼다. 같은 머티리얼을 쓰는 다른 씬(필드·챕터 01)은 영향이 없다.
- 복사본 .meta 의 userData 에 원본 GUID(`tff-src:<guid>:<localId>`)가 적혀 있다. 되돌리기는 이것만 보고 원본을 찾는다 — 기록 파일이 따로 없다.
- 이미 있는 복사본은 다시 만들지 않는다. 복사본 값을 손봐도 다음 [적용] 에서 덮어쓰지 않는다. 원본 값으로 다시 만들고 싶으면 그 복사본을 지우고 [적용].
- 대상: MeshRenderer 의 BCM/BCM_Toony_shader 칸. 제외 — 캐릭터·무기(부모에 Animator), 발광 머티리얼(가로등 전구·간판, `_EMISSION` 켜짐), 숨은 런타임 오브젝트. 풀잎·물·데칼·빛 웅덩이는 처음부터 전용 셰이더라 손대지 않는다.
- 알파 컷아웃(나무 잎 카드·덤불·화분) → 식생 셰이더, 나머지 → 외곽선 셰이더.

- CityBuilder(도시 테스트 씬 생성)로 도시를 다시 만들면 BCM 으로 돌아온다. 다시 [마지막].
